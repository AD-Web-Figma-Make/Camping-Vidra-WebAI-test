# Plan: Inici (Home) Page — Càmping Vidrà

## Context

The Inici page already has a rough monolithic implementation in `src/App.tsx` built without Kit components and with hardcoded hex colors instead of CSS custom properties. This plan governs a full rewrite of that file to:

- Replace every section with the correct Digital Agency Kit structural component
- Apply all colors, fonts, and shadows through the CSS custom properties already defined in `src/index.css` via Tailwind v4 `@theme`
- Keep all copy verbatim from the wireframe (content source)
- Preserve the wireframe's section order (layout authority)
- Keep visual identity from the Camping Baliera style frame (style authority)
- Wire the Witbooking `BookingWidget` variant (booking provider constraint)

## 4 · Risk and Recovery

| Risk | Detection Signal | Fast Repair |
|---|---|---|
| **Kit component import fails (empty barrel)** — `dist/index.js` is `/* empty css */`, so `import { X } from '@make-kits/digital-agency-kit'` returns undefined at runtime | Component renders nothing; React "not a function" error in console | Import directly from component path: `@make-kits/digital-agency-kit/dist/app/components/ComponentName.js` |
| **CSS variable not resolving in Tailwind** — `bg-primary` shows no color if `@theme` block is malformed or `@import 'tailwindcss'` order is wrong | Section backgrounds/text colors appear as browser defaults | Confirm `@import url(...)` is the first line in `index.css`, `@import 'tailwindcss'` is second, `@theme {}` is third; verify var names match exactly |
| **Style leakage from wireframe** — Kit component defaults (gray palette, Inter font) bleed through if Kit classNames are not overridden | Page looks like a generic wireframe / Kit preview, not the Camping Baliera brand | After each component is assembled, compare against style source screenshot; strip any `text-gray-*`, `bg-gray-*`, `font-['Inter:*']` classes; apply project token classes |
| **Copy drift** — generated CTAs, headings, or descriptions differ from wireframe text | Text in rendered page doesn't match wireframe screenshot or transcribed copy | Re-read wireframe design context file; restore exact wireframe strings; no paraphrasing |
| **BookingWidgetWitbooking labels in wrong language** — Kit Witbooking default uses Spanish ("Fechas de su estancia") | Booking bar shows Spanish while rest of page is Catalan | Override via wrapper or prop injection: wrap the Kit component and patch label text through CSS `::before` or a thin local wrapper that substitutes the Catalan strings. If Kit props don't support label override, create a thin `CampingBookingWidget` component that wraps `BookingWidgetWitbooking` and replaces the text nodes |
